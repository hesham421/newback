**What the plan contains:**

  - API-SEC-028/029/030 list, issue and revoke a service account's credentials.
  - API-SEC-031 is the client-credentials token endpoint.

  - The token is a signed JWT carrying the id of the credential it was issued from.
  - Every request made with it is checked against the credential and the account as they are right now, and the result is never cached. So revoking a credential or deactivating the account takes effect on the very next request.
  - There is no session row and no refresh token.
