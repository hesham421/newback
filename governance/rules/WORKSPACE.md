  `deploy.sh`); flagged separately as FIX 7 in the governance-drift report

  (a single shared AI-governance repo that `backend`, `frontend`, and
  `deploy` all depended on). That model no longer applies: this repo's root
  `CLAUDE.md` states outright that "There is no external sibling governance
  repository — everything a session in this repo needs lives inside
  `backend/governance/`." As of 2026-08-28, this folder no longer exists on
  disk at either candidate sibling location — it has already been removed
  (by whom/when is not recorded). Several files generated by the old model
  (`manifest.json`, `_agent3-state.json`, `execution-state.json` for
  ORG/NOTIFICATION/FILESVC) still carried absolute paths pointing into it;
  those were corrected to relative paths in the same pass that discovered
  this folder was gone. If you find a reference to `governance-repo/`
  anywhere else, it is stale documentation, not a live dependency.
